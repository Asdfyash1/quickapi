# Changelog

All notable changes to QuickAPI will be documented in this file.

## [1.0.0] - 2025-04-29

### Added
- FastAPI project scaffolder CLI with Rich terminal output
- One-command project generation with routes, models, DB, Docker, tests
- Multiple template features: auth, CRUD, WebSocket, background tasks
- Jinja2-based template system for clean code generation
- AI-powered route generation from natural language descriptions
- AI-powered endpoint addition to existing projects
- Multi-provider AI support: OpenAI, Google Gemini, NVIDIA
- Automatic API key detection with fallback chain
- Comprehensive test suite (6 tests)
- GitHub Actions CI with Python 3.9-3.12 matrix
